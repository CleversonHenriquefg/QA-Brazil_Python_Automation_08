# Projeto 8 — Automação Web com Selenium

Testes automatizados do Urban Routes usando Python, Selenium, Pytest e Page Object Model (POM).

## Como executar

```bash
python -m pip install -r requirements.txt
python -m pytest main.py -s
```

> O endereço do servidor ativo deve ser atualizado em `data.py` quando a TripleTen reiniciar o ambiente.
